# cosense-images

Cosenseのページに貼る画像（PNG・JPG・SVG）の置き場である。

## 注意

このリポジトリは公開である。置いた画像は全部、一般公開になる。置く前に、写っているものを確認すること。

## 置き場所

月ごとのフォルダ `YYYY-MM/` に置く。ルートには置かない。

```
2026-10/galilean-rays.png
2026-10/iphone-home-screen-test.png
```

ファイル名は、内容が分かる英小文字とハイフンにする。図のSVGの元データは、PNGと同じフォルダに置いてよい。

一度置いたファイルは、移動・改名・削除しない。リンクが切れる。

## 使い方

画像をこのリポジトリに追加し、GitHub上のraw URLをCosenseのページに `[URL]` の形で貼る。

```
https://raw.githubusercontent.com/ojimpo/cosense-images/main/YYYY-MM/<ファイル名>
```
